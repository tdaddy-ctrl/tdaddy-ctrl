## Projects

### [DARK GRID](https://github.com/tdaddy-ctrl/DarkGrid)

An interactive simulation exploring how robotaxi operators could respond to a citywide disruption. DARK GRID runs the same deterministic scenario with two dispatch approaches—first-in, first-out (FIFO) and impact-based triage—so their trade-offs can be compared.

The project brings together:

- A simulation of robotaxis, operator requests, blocked vehicles, and an ambulance response.
- Dispatch prioritization and compatible-request batching, with automatic and manual operator modes.
- San Francisco road-network routing alongside a generated test grid.
- A 3D tactical view, vehicle movement, and an ambulance follow camera.
- Operational metrics and incident-report analysis, with an offline fallback when the optional AI service is not configured.

**Built with:** TypeScript, React, Next.js, and Vitest.

> DARK GRID is a demonstration simulation, not a live dispatch system. Its behavior and metrics are modeled assumptions.

### [Instanimals](https://github.com/tdaddy-ctrl/mainpage) *(private)*

A web concept focused on helping shelters connect animals with foster families. The landing page frames the idea around finding a foster animal through one application, and introduces a simple “how it works” flow, success-story content, and shelter-partner messaging.

This repository is primarily a frontend experience/prototype; the content describes the product idea and should not be read as evidence of a live shelter network or completed adoption service. It also has separate client and server projects and a small shared API-contract area.

**Built with:** React, TypeScript, Vite, Tailwind CSS, and an Express-based server setup.

### [COMSC140](https://github.com/tdaddy-ctrl/COMSC140)

An early Python coursework repository. Its current program is a small command-line “Hello, World!” example, using a `main()` function and Python’s standard script-entry guard—a starting point for practicing programming fundamentals.

**Built with:** Python.
